# Projetos

Esta pasta centraliza todos os projetos criados pelo assistente (Muse Spark / OpenCode).

## Regra de salvamento automático

- Todo projeto novo vai para `projetos/<nome-do-projeto>/`
- Arquivos locais de trabalho ficam em `C:\Users\chiba\chibangarx\projetos\`
- Repositório canônico: `https://github.com/chibangar/chibangarx` (branch `main`)
- A cada tarefa concluída: commit + push automático para o GitHub

## Estrutura

```
projetos/
  README.md
  <nome-do-projeto>/
    README.md
    src/
    ...
```

## Pasta local duplicada

Existe uma cópia em `C:\Users\chiba\projects\chibangarx\`, mas a pasta oficial para novos projetos é `C:\Users\chiba\chibangarx\projetos\`.
