## ChibangaRx v2.45.24

### Segurança

- Reforçada a separação entre a interface e o processo principal do Electron.
- Restringidos canais IPC, comandos de manutenção, downloads e desinstalações.
- A aplicação passa a iniciar sem privilégios de administrador por defeito.
- O processo de distribuição exige tags assinadas, binários Authenticode, hashes SHA-256, SBOM e proveniência verificável.

### Distribuição

- Cada versão válida é publicada como GitHub Release com os respetivos instaladores e metadados de segurança.
