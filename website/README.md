# Site ChibangaRx — publicação no InfinityFree

Esta pasta contém um site estático e não interfere com a aplicação Electron.

1. Crie ou aceda à sua conta em https://dash.infinityfree.com/accounts/create.
2. No painel, crie um domínio/subdomínio e abra o **File Manager**.
3. Entre na pasta `htdocs`, remova apenas a página inicial padrão do alojamento e carregue o conteúdo desta pasta (`index.html`, `styles.css`, `script.js` e `assets`).
4. Confirme que `index.html` fica diretamente dentro de `htdocs`.
5. Abra o domínio atribuído e teste o botão de download.

O botão principal aponta sempre para a release mais recente no GitHub. Não coloque credenciais, ficheiros privados ou música comercial nesta pasta.
